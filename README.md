# TradeForge Engine

A modular trading engine for automated strategies, signals, and execution.

## Features

- ✅ Market data from Twelve Data API
- ✅ PostgreSQL database for caching
- ✅ FastAPI REST endpoints
- 🔄 Signal generation (coming)
- 🔄 Backtesting (coming)
- 🔄 MetaTrader integration (coming)

## Quick Start

### Prerequisites
- Python 3.14+
- PostgreSQL

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/tradeforge-engine.git
cd tradeforge-engine/backend/engine/src
pip install -r requirements.txt
